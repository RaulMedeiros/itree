# Política de segurança

## Como reportar uma vulnerabilidade

Não abra uma issue pública para falhas de segurança. Use o relato privado do GitHub:

1. Abra a aba **Security** do repositório [RaulMedeiros/itree](https://github.com/RaulMedeiros/itree).
2. Escolha **Report a vulnerability** (Security Advisories) e preencha o formulário.

Só quem mantém o repositório vê o relato, e a conversa e a correção acontecem ali.

## O que incluir no relato

- O que foi encontrado e qual o efeito (por exemplo, dado de outro território visível).
- Onde: tela, rota da API ou arquivo, e a versão ou o commit.
- Passos para reproduzir, com dados sintéticos. Não inclua dados pessoais reais.
- Se houver, uma sugestão de correção.

## Prazo de resposta

A combinar com a prefeitura. Ainda não há prazo definido para confirmar o recebimento, avaliar e corrigir.

## O que não fazer

- Não acesse, altere nem apague dados que não sejam seus.
- Não faça testes de negação de serviço nem de engenharia social contra pessoas.
- Não divulgue a falha antes da correção.
