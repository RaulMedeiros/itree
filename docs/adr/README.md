# Registros de decisão de arquitetura (ADR)

Cada ADR registra uma decisão técnica: contexto, decisão, alternativas e
consequências. ADRs aceitas não são editadas no mérito; mudanças de rumo geram
nova ADR que **substitui** a anterior.

Status: `Proposto` · `Aceito` · `Substituído por ADR-XXXX` · `Descartado`.
